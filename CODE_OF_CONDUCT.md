# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions focused on the work.
Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behavior privately to the maintainer through GitHub (the repository owner's profile).
The maintainer may remove, edit or reject contributions and comments that violate this code, and may temporarily
or permanently ban participants who do so.
